CAFFEINE TRACKER PWA

GitHub Pages setup:
1. Create a GitHub repository.
2. Upload every file in this folder to the main branch.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for GitHub Pages to publish.
7. Open the HTTPS site in Safari on iPhone.
8. Safari Share > Add to Home Screen > Add.

The app stores logs locally in the browser/device and supports JSON backup/export.
